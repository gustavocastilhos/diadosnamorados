## 💡 Sobre o Projeto

Cansado dos clichês de Dia dos Namorados né? Este projeto supera as expectativas. Ao abrir o site, o usuário se depara com uma tela cinza e um contrato de **Termos e Condições (EULA)** cheio de paradas jurídicas e regras de relacionamento (como a tributação de batatas fritas 🍟).

Apenas após ler tudo (rolar o scroll até o final) e passar por um sistema de validação estressante, a verdadeira surpresa é revelada... o design corporativo some e dá lugar a um cartão romântico super animado, com direito a carrossel de fotos e uma chuva de corações!

## ✨ Funcionalidades (O que tem sob o capô)

* **Validação de Leitura (Scroll):** O botão de aceite só é desbloqueado se o usuário rolar o texto até o último pixel.
* **Botão Fujão:** Um botão de "Recusar" que usa JavaScript para fugir do cursor do mouse (ou do toque no celular), mudando de texto para impedir que a pessoa desista.
* **Gerenciamento de Estados:** Um modal dinâmico que muda de comportamento e "grita" com o usuário dependendo de quantas vezes ele clica no botão principal.
* **Troca de Temas Dinâmica:** Injeção de classes via JavaScript que altera todo o CSS e a atmosfera da página instantaneamente.
* **Carrossel de Imagens:** Um slider funcional construído para alternar as fotos do casal dentro do cartão.
* **Fábrica de Partículas (Chuva de Corações):** Geração dinâmica de elementos via JavaScript, manipulando a DOM para criar dezenas de emojis de coração. O CSS utiliza `@keyframes` com durações e atrasos calculados matematicamente (`Math.random()`) para criar um efeito de queda e balanço super natural e contínuo por toda a tela.
* **Animações CSS Avançadas:** Uso de `@keyframes` para criar efeitos suaves de surgimento e pulsação contínua no cartão final.

## 🚀 Como rodar o projeto localmente

Não é necessário nenhum ambiente complexo para rodar este site. 

1. Baixe os arquivos do projeto.
2. Abra o arquivo `index.html` diretamente no seu navegador, ou utilize a extensão **Live Server** no VS Code para uma melhor experiência.
